# CampusClaw 本地作业版规约

## 目标与边界
当前交付是“梁老师 · A班”登录后的可运行教师首页及截图；提供材料基础链路以保证页面数据可复现。示例材料通过受保护上传接口写入，禁止前端伪造列表与统计。不声称完成用户未提供的第 2 课 OpenSpec change 或课程完整 Go/MySQL 验收。

## 实现选择
- 使用 Python 标准库降低本地启动成本，SQLite 提供真实持久化和事务。
- 原始文件字节与正文在数据库同事务写入；失败时全部回滚，无额外磁盘文件。
- 使用随机不透明会话，服务端保存用户身份、角色、班级关联。前端隐藏操作只改善界面，后端仍独立检查权限。
- 所有材料查询使用会话 `class_id`；不存在/跨班使用相同 404。
- Markdown 经过标签、属性及链接协议白名单清理；不渲染可执行 HTML。

## 验收场景
1. 正确密码登录后 `/api/me` 返回教师/学生身份及固定班级；错误密码与不存在账号同为 401、相同提示。
2. 未登录查询材料、正文、原文件时返回 401，仅含错误信息。
3. 教师上传 UTF-8 TXT/MD 后，两张表同事务写入；刷新后列表、统计与正文一致。
4. 同班学生能查询与下载；调用上传接口返回 403，即使伪造 role。
5. B班用户访问 A班材料详情或下载返回 404；列表参数不能切换班级。
6. 扩展名不支持返回 415，超过 2 MB 返回 413，非法 UTF-8/空内容返回 422；失败无数据残留。
7. 数据库入库异常返回 500；材料行回滚。
8. 写请求 CSRF 校验失败返回 403；退出或过期后原会话不能读取材料。
9. 首页显示梁老师、教师、A班、材料与知识条目数量、搜索和上传入口。
10. 列表/网格、正文预览、浅/深色、快捷操作和移动端可用。

## 非目标
不做管理员、跨班查询、向量库、RAG、对话、自动备课、命题、作业和成绩处理。
