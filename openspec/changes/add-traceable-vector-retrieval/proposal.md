# 可追溯的班级知识库检索

## Why
第 3 课只支持材料标题筛选。现在需要从正文中定位证据，且每个结果都可以验证出处。

## What changes
新增原文切片、SQL 全文索引、Qdrant 向量索引、keyword/vector/hybrid 检索及来源定位 UI。教师与学生均可检索本班；上传仍仅教师可用。老材料启动时补建切片，向量在后台建立。

## Non-goals
不生成自由形式的 AI 答案，不做跨班检索、管理员、材料编辑删除。本次沿用 Python + SQLite，本地 Qdrant 默认无需 Docker；不声称已迁移到课件的 Go + MySQL 栈。返回的是原文证据，不把低相关结果包装为答案。
